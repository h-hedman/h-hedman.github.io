Clinical NLP Pipeline for GLP-1 Medication Abstraction

This project demonstrates a compact, end-to-end healthcare NLP pipeline for transforming unstructured clinical notes into structured, analysis-ready labels using synthetic GLP-1 medication data.

  • Ingests heterogeneous clinical inputs (notes, prescriptions, diagnoses)
  • Normalizes and parses free-text medication mentions
  • Applies temporal and contextual logic for label abstraction
  • Produces harmonized, tabular outputs for downstream analytics

Emphasizes multimodal data harmonization and scalable clinical abstraction workflows commonly used in real-world healthcare NLP pipelines. See the full repository for implementation details.
