# Hayden Hedman Portfolio

Source for [h-hedman.github.io](https://h-hedman.github.io/), containing project summaries, navigation, publications, and supporting site assets.

## Project source repositories

- [Healthcare Data Science](https://github.com/h-hedman/healthcare-data-science): healthcare projects, including [Healthify](https://github.com/h-hedman/healthcare-data-science/tree/main/healthify-flu-app) and [Summit County Public Health](https://github.com/h-hedman/healthcare-data-science/tree/main/scph).
- [Transportation Analytics](https://github.com/h-hedman/transportation-analytics): public transportation work, beginning with NCFO ferry capacity and utilization.

## Updating the site

Edit the relevant HTML page and assets, check links and rendering, then commit and push to `main`. GitHub Pages publishes this repository. Keep project code in its domain repository and link to it from project summaries.

Healthify's [static site](https://h-hedman.github.io/healthcare-data-science/healthify-flu-app/) is published from the healthcare repository; its interactive apps run separately on Posit Connect Cloud. The retired Automated Epi Report is omitted from project listings, while its documentation page remains available.
