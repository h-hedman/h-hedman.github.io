Georgia Tech — Predictive Decision Trees for Occupational Exposure

Simulation-based modeling of chemical exposure risk and asthma-like symptoms to support occupational health monitoring in data-scarce environments.

Developed an exploratory simulation tool and supervised learning pipeline to model how routine exposure to common workplace irritants may relate to asthma-like symptoms among professional cleaning staff working in laboratory and healthcare-adjacent environments. The work emphasizes practical risk modeling when direct exposure surveillance data are limited.

Paper: DOI: 10.3390/laboratories3010002
Code: GitHub repository (reproducible pipeline)

What I Built

  • Simulation framework: Generated a 20,000-record synthetic cohort parameterized from published occupational exposure research to support structured scenario testing.
  • Modeling pipeline: Trained and compared four tree-based classifiers (Decision Tree, Random Forest, Gradient Boosting, XGBoost) for predicting asthma-like symptoms.
  • Safety-first evaluation: Tuned decision thresholds to prioritize recall (minimizing false negatives) given workplace safety implications and outcome rarity.
  • Interpretability: Used SHAP-based global feature importance to support transparent risk-driver communication and model review.
  • Reproducibility: Provided end-to-end code for data generation, feature engineering, model training, and evaluation.

Transferable Technical Signals

  • Risk modeling under severe class imbalance (AUC-PR emphasis, threshold tuning)
  • Tree-based ML for nonlinear exposure–outcome relationships
  • Feature engineering informed by domain constraints and operational use
  • Model interpretation and communication for non-technical stakeholders

Note: This work uses simulated data and is intended as an exploratory framework for decision support, not as a clinical diagnostic model.
